## 📌 About the Project

**[CompareHeightTool (compareheighttool.com)](https://www.compareheighttool.com)** is designed to provide millimeter-accurate, side-by-side height comparisons for people, couples, celebrities, and everyday objects. All calculations and silhouette renderings run 100% client-side in the browser for maximum speed, security, and data privacy.

### Key Features & Capabilities:
- **Interactive Precision Canvas**:
  - Horizontal drag-and-drop silhouettes with touch-friendly mobile navigation.
  - Realistic gender/body outlines (Male, Female, Child, and Object markers).
  - Dual measurement display with instant conversion between Metric (`cm`) and Imperial (`ft / in`).
  - High-resolution PNG chart export for sharing, presentations, and social media.
- **Pre-Configured Comparison Hubs**:
  - [Celebrity Height Comparisons](https://www.compareheighttool.com/celebrities) (e.g., Zendaya vs Tom Holland, The Rock vs Kevin Hart, Lionel Messi vs Cristiano Ronaldo).
  - [Couples Height Gap Analysis](https://www.compareheighttool.com/couples) (e.g., 5'2" vs 6'0", 5'4" vs 5'11", 5'6" vs 6'0").
  - [Everyday Object Scale References](https://www.compareheighttool.com/objects) (Door frames, refrigerators, basketball hoops).
  - [Research & Measurement Guides](https://www.compareheighttool.com/guides) on human posture, morning vs evening stature, and global demographic averages.
- **Multilingual Support (6 Locales)**:
  - Full native support for [English](https://www.compareheighttool.com), [Español](https://www.compareheighttool.com/es), [Deutsch](https://www.compareheighttool.com/de), [Français](https://www.compareheighttool.com/fr), [Português](https://www.compareheighttool.com/pt), and [日本語](https://www.compareheighttool.com/ja).
  - Bidirectional `hreflang` alternate tags and canonical URL structures.
- **Rich Structured Data**:
  - Schema.org compliant `WebApplication`, `BreadcrumbList`, `FAQPage`, and `Article` structured data.
- **100% Client-Side Privacy**:
  - No height data, names, or silhouettes are sent to any remote server or stored in cookies.

## 🚀 Tech Stack

- **Framework**: Next.js 16 (App Router, Turbopack)
- **UI Library**: React 19
- **Styling**: Tailwind CSS v4
- **Typography**: Optimized Google Fonts (`Plus Jakarta Sans`, `Newsreader`, `JetBrains Mono`)
- **Icons**: Lucide React
- **Hosting & Infrastructure**: [Vercel](https://vercel.com) Edge Network (Global CDN with sub-second response times)

## 🛠️ Local Development

```bash
# 1. Clone repository
git clone https://github.com/LAKSHAYRATRA/compareheighttool.git
cd compareheighttool

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Open in browser
# Navigate to http://localhost:3000
```

## 🌐 Production Deployment

The project is optimized for deployment on **[Vercel](https://vercel.com)**:
1. Import the repository into your Vercel Dashboard.
2. Vercel automatically detects Next.js build settings.
3. Add your custom domain (`compareheighttool.com` and `www.compareheighttool.com`).
4. Production builds and edge routing execute automatically on every `git push`.
